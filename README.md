# ComfyUI Colab — ferramentas de IA para o ecossistema Lia

Repositório de apoio para fluxos de ComfyUI/Colab e nós customizados utilizados em experimentos do ecossistema Lia. Consulte os notebooks, workflows e diretórios existentes neste branch para confirmar o que está implementado e validado.

O nó customizado Lia, quando presente, deve permanecer identificável como componente independente, com dependências, versão e licença próprias.

## Padrões e segurança

- [docs/BRAND-STANDARDS.md](docs/BRAND-STANDARDS.md) — princípios comuns da marca Lia.
- AGENTS.md — instruções para agentes.
- Não envie imagens, meshes, prompts ou outros assets privados a serviços externos sem autorização explícita.
- Não presuma que o nome Lia concede direitos sobre assets, modelos ou dependências de terceiros.
